## The security-sweep release + the launch sweep

All 12 findings from the first real AI pentest (ATL-242: 1 high, 5 medium, 5 low, 1 info) are fixed and live — with an executed live gate behind every single one, not just unit asserts. The hosted UI was rebuilt to computed WCAG 2.2 AA, and the repo got the launch treatment (docs, brand, packaging).

### Security
- **Deployment-aware rate-limit identity** + identity-independent **global window** — rotating `CF-Connecting-IP` no longer mints buckets; IPv6 spellings share one bucket (vuln-0002/0010)
- **`/notify` throttled + pruned** — it was the only unthrottled write (vuln-0001); **one-mailbox email validation** closes comma-injection recipient expansion (vuln-0011)
- **Derived work bounded**: `MAX_STATEMENT_ROWS` (200k), sync reconcile (event loop stays free — health worst 594 ms during a 150k-row run, was a 6.3 s full stall), 2-slot concurrency semaphore (vuln-0004)
- **Formula-initiator set complete** (`-` included), money/date/epoch bounds at every parser entry, `csv.Error`→`ValueError`, no more 500s on malformed input (vuln-0003/0005/0008/0009)
- **PDF/OCR work ceilings**: 50 pages / 2 MB decoded stream / 2 M chars / 40 MP raster guard + 120 s OCR timeout — the 39 KB/100-page bomb that cost 125 s CPU is refused in <1 ms (vuln-0012)
- SBI netbanking latent `NameError` fixed (vuln-0007); quadratic narration reassembly made linear (vuln-0006)

### UI
- Complete design-token rewrite of `_style.html`; every fg/bg pair passes WCAG 2.2 AA by computed ratio. axe-core in real Chromium: **0 violations on all page types × both colour schemes**, verified locally and against the live site
- Focus-visible rings, styled file buttons, `<main>` landmarks, brand mark, favicon (+ real `.ico`), OpenGraph share card

### Docs & repo
- README launch rewrite (banner, badges, screenshots), `CHANGELOG.md`, `docs/USER-GUIDE.md`, `docs/UI-AUDIT.md`; architecture/testing docs refreshed; packaging fixed (PEP 639, `py.typed`, classifiers/keywords/URLs)

**Self-check: 77/77. CI: green on 3.10/3.11/3.12 + zero-deps + boot-canary integration.**
The Strix CI scan workflow was retired this release (D-43) — it found the 12 defects above, then became a permanently-red gate with no funded model; live per-fix gates replaced it.
